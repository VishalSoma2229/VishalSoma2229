# 🚀 Featured Projects

## 🏦 01 — Banking Data Platform

A production-inspired end-to-end banking data platform implementing **Medallion Architecture (Bronze → Silver → Gold)** with PySpark, Apache Airflow, MinIO, Duck-UI, Snowflake and Docker.

### 🔥 Highlights

- ⚡ PySpark-based ETL across **7 banking domains**
- 🥉 Bronze → 🥈 Silver → 🥇 Gold data lake architecture
- ❌ Rejected-record layer for data-quality failures
- 🔄 Separate Airflow DAG for each banking domain
- 🪣 MinIO as S3-compatible object storage
- 🦆 Duck-UI for interactive SQL analytics
- ❄️ Snowflake warehouse with Star Schema
- 🔄 Snowflake Streams & Tasks for CDC
- 🔁 `MERGE`-based incremental processing
- 🔐 Dynamic Data Masking (DDM)
- 🛡️ Role-Based Access Control (RBAC)
- 🐳 Dockerized infrastructure
- 💻 Same processing platform supports containerized and local execution

### 🧱 Architecture

```text
Banking Sources
      │
      ▼
   PySpark
      │
      ▼
🥉 Bronze / MinIO
      │
      ▼
Validation & Cleaning
      │
      ├──────────────► ❌ Rejected
      │
      ▼
🥈 Silver
      │
      ▼
Business Transformations
      │
      ▼
🥇 Gold
      │
      ├──────────────► 🦆 Duck-UI
      │
      ▼
   Snowflake
      │
      ▼
Star Schema + CDC + Governance
```

### 🛠️ Tech Stack

`PySpark` `Apache Airflow` `MinIO` `Duck-UI` `Snowflake` `Docker` `Parquet`
